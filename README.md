# European Bank Customer Churn Analysis

A Streamlit dashboard for analyzing customer churn and banking patterns using the European Bank Customer dataset.

## Project Overview

This project analyzes customer churn based on different customer characteristics such as geography and gender. The interactive dashboard helps identify churn patterns and compare customer segments.

## Features

- Interactive country filter
- Interactive gender filter
- Total customer count
- Exited customer count
- Churn rate calculation
- Average customer balance
- Customer distribution by country
- Customer churn distribution visualization
- Active vs inactive member churn analysis
- Age-wise churn analysis

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib

## Dataset

The project uses the European Bank Customer Churn dataset containing customer information and churn status.

## Dashboard

The project is deployed using Streamlit Community Cloud.

The dashboard allows users to interact with the data using country and gender filters.

## Key Objective

The main objective of this project is to analyze customer churn patterns and understand which customer segments have higher churn rates.
